# 🛍️ Cara — Full-Stack Modern eCommerce Storefront

A responsive and modern full-stack eCommerce web application built with Vanilla JavaScript, Node.js, Express, and MongoDB Atlas. Features real-time cart state management, simulated UPI checkout, and cloud database persistence.

- **Live Storefront:** [https://cara-store-beta.vercel.app](https://cara-store-beta.vercel.app/)
- **Backend API:** [https://cara-store-fdui.onrender.com](https://cara-store-fdui.onrender.com/)
- **GitHub Repository:** [cara-store](https://github.com/abhishekmishra34281234-stack/cara-store)

---

## ✨ Features

- **Dynamic Catalog:** Interactive product grid rendered with dynamic pricing and ratings.
- **Cart Management:** Real-time badge counter, quantity adjustments, item removal, and persistent state via `localStorage`.
- **Cloud Database:** Production orders stored in **MongoDB Atlas** via a dedicated REST API.
- **Microservice Architecture:** Decoupled frontend deployed on **Vercel** and backend services hosted on **Render**.
- **Responsive Layout:** Mobile-first, fully responsive design styled with modern CSS.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), FontAwesome
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Deployment & Hosting:** Vercel (Frontend), Render (Backend)
